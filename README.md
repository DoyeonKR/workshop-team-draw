# workshop-team-draw

팀 워크숍 하루를 진행하는 로컬 웹 서버. 노트북 한 대에서 서버를 켜고, 참가자는 같은 Wi-Fi 또는 인터넷 주소(Cloudflare 임시 터널)로 휴대폰에서 접속한다.

Python 표준 라이브러리만 사용한다(설치할 패키지 없음). 화면은 HTML 파일 하나씩이고, 실시간 갱신은 SSE와 짧은 주기 조회를 같이 쓴다.

> 공개 저장소용으로 참가자 이름은 `참가자01`~`참가자18`, 진행자는 `사회자`, 협력사는 `PartnerA`/`PartnerB` 로 바꿔 두었다. 실제 행사 기록(`data.json`)은 포함하지 않는다.

## 화면

| 주소 | 용도 | 비고 |
|---|---|---|
| `/` | 팀 뽑기 | 닉네임 입력 → 본명 선택 → 추첨. 고정 리더팀 + 랜덤 2팀, 팀장 무작위, 결과 공개 연출. 사회자 이름을 고르면 관리자 화면 |
| `/games` | 게임 진행(빔프로젝터용) | 퀴즈 빙고, 몸으로 말해요, 캐치마인드, 닉네임 특별상, 참여왕 투표, 남/집 투표, 2차 메뉴, 최종 랭킹 |
| `/word` | 캐치마인드 그리는 사람 휴대폰 | 제시어 표시, 손가락 그림판(큰 화면과 동기화), 정답·패스 |
| `/vote` | 닉네임 특별상 투표 | 노트북 한 대에서 돌아가며 투표 |
| `/mvp` | 참여왕 투표 | 각자 휴대폰으로 QR, 1인 1표, 자기 자신 제외 |
| `/stay` | 남겠다 / 집에 가겠다 | 다시 누르면 선택 변경 |
| `/menu` | 2차 메뉴 모으기 | 이름 없이 입력, 같은 메뉴는 묶어서 많을수록 크게 |
| `/lottery` | 카드 뽑기(제비뽑기) | 진행자 큰 화면 위쪽에서 참여 인원·당첨 인원(참여자 명단은 선택)을 정하면 카드가 섞이고, 각자 한 장씩 뒤집어 PASS / 당첨 확인. 당첨은 악어 턱이 덥석 무는 연출. `/card`, `/draw` 도 같은 화면 |
| `/pinball` | 핀볼 추첨 | 참여 인원·당첨 인원(이름 선택)을 정하고 출발하면 공이 10개 구간(핀 밭·바람개비·부스터·범퍼·포털·진자 해머·움직이는 발판·풍차·블랙홀)을 굴러 내려가 먼저 도착한 순서대로 당첨. `/marble` 도 같은 화면 |
| `/timetable` | 전체화면 타임테이블 | 현재 순서 강조, 휴식 타이머(B), 감사 장면(T) |

## 실행

```bash
python3 server.py            # 기본 포트 8023
python3 server.py --port 9023
```

macOS 에서는 `start.command` 를 더블클릭해도 된다. 같은 Wi-Fi 의 다른 기기는 창에 표시되는 `http://<IP>:8023/` 로 접속한다.

### 인터넷(모바일 데이터)에서 접속

```bash
brew install cloudflared     # 처음 한 번
./tunnel.command             # 서버를 먼저 켠 뒤 실행
```

`https://<임의>.trycloudflare.com/` 주소가 생기고, 화면의 QR 코드가 이 주소로 자동으로 바뀐다. 연결이 끊기면 30초 간격으로 확인해 새 주소로 다시 연결한다.

## 설정

`server.py` 맨 위 상수에서 바꾼다. 바꾼 뒤 `data.json` 을 지우고 재시작한다.

| 상수 | 의미 |
|---|---|
| `ROSTER` | 참가자 명단(본명) |
| `LEADERS` | 무조건 리더팀에 들어가는 사람 |
| `ADMIN` | 진행자(관리자 화면 진입용 이름, 추첨 제외) |
| `GOAL`, `LEADER_EXTRA` | 총원, 리더팀에 랜덤으로 더 들어가는 인원 |
| `GAME_PASSWORD` | 게임 화면 비밀번호. 빈 값이면 비밀번호 없음 |
| `CHARADES_DEFAULT`, `CATCH_DEFAULT` | 몸으로 말해요·캐치마인드 제시어(명사만, 두 게임 통틀어 중복 출제 없음) |
| `BINGO_DEFAULT` | 퀴즈 빙고 16칸 주제와 유튜브 링크 |

## 파일

| 파일 | 내용 |
|---|---|
| `server.py` | HTTP 서버, 상태 관리(`data.json` 에 저장), 모든 API |
| `index.html` | 팀 뽑기 화면 |
| `games.html` | 게임 진행 화면 |
| `word.html`, `vote.html`, `mvp.html`, `stay.html`, `menu.html` | 휴대폰용 화면 |
| `lottery.html` | 카드 뽑기 (큰 화면·휴대폰 겸용) |
| `pinball.html` | 핀볼 추첨 (진행자 화면에서 혼자 돌아감, 서버 저장 없음) |
| `timetable.html` | 전체화면 타임테이블 |
| `start.command`, `tunnel.command` | macOS 더블클릭 실행용 |
| `사용법.txt` | 진행자용 사용 설명서 |

## 주의

- 인증은 최소한이다. 진행자 이름만 고르면 관리자 화면에 들어가고, 인터넷 주소를 아는 사람은 누구나 화면을 열 수 있다. 행사 중 짧게 쓰는 용도로만 사용한다.
- 퀴즈 빙고 영상은 외부 유튜브 링크다. 퍼가기를 막은 영상은 팝업 창으로 재생한다.
