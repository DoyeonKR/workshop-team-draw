10월23일 QE합동 워크샾 팀뽑기 서버 사용법

[켜기]
  start.command 를 더블클릭 (또는 터미널에서: python3 server.py)
  창에 나오는 "다른 PC·휴대폰 접속" 주소를 참가자에게 공유한다.
  참가자는 서버 PC와 같은 Wi-Fi(사내망)에 연결돼 있어야 한다.

[추첨]
  재치있는 닉네임 입력 → 아래 명단에서 본명 선택 → 추첨하기.
  총원 18명(사회자 제외) → 리더팀 6 / 1팀 6 / 2팀 6.
  참가자01·참가자04·참가자07·참가자03·참가자02은 무조건 리더팀, 나머지 13명 중 1명이 랜덤으로 리더팀 합류.
  팀장은 팀마다 1명, 추첨 순서와 상관없이 무작위.
  명단·리더팀·총원은 server.py 맨 위 ROSTER / LEADERS / GOAL / LEADER_EXTRA 에서 바꾼다(바꾼 뒤 data.json 삭제 후 재시작).

[게임 진행 — http://서버주소:8023/games]
  진행자 화면 하나(빔프로젝터에 띄운 노트북)에서만 진행한다.
  비밀번호 없이 바로 들어간다(2026-10-23 해제). 새로고침해도 진행 중이던 라운드·점수는 그대로다.
  비밀번호를 다시 걸려면: server.py 맨 위 GAME_PASSWORD = "0000" 처럼 넣고 서버 재시작.
  팀뽑기 화면 위쪽 [🎮 게임 진행 화면] 버튼으로도 들어간다.
  게임 화면 위 [⛶ 전체화면] 버튼 = 브라우저 전체화면(다시 누르거나 Esc 로 끔). 빔프로젝터(1280×720)에서도 스크롤 없이 한 화면에 들어온다.
  시작 전 그 노트북 크롬에서 이 주소의 '팝업 허용'을 해 두면 좋다(빙고 일부 영상용).

  🎵 퀴즈 빙고 (4x4, 16개 주제)
    칸 클릭 → 퀴즈 영상 재생. 맞힐 때마다 팀 +1 (키보드 1·2·3, Shift+숫자 = −1).
    영상이 끝나면 [칸 확정](Enter) → 가장 많이 맞힌 팀이 칸을 가져감. 동점이면 팀을 직접 고름.
    가로·세로·대각선 4칸 먼저 = 빙고 승리. 빙고가 없으면 [빙고 없이 종료]로 칸 최다 팀 승리.
    90·00·10·20년대 노래, OST 영화 1·2편, 애니메이션 노래, 국기 영상은 올린 사람이
    퍼가기를 막아 둬서 [팝업 창으로 재생]을 누르면 화면 왼쪽 팝업에서 재생된다
    (오른쪽 점수판은 그대로 보임). 링크는 [칸 편집]에서 바꿀 수 있다.
  🙆 몸으로 말해요: 한 팀씩, 팀당 7분. 팀 버튼 → 3초 뒤 시작.
    팀별로 한 팀씩 차례대로 하고, 팀 안에서는 팀원이 순서대로 한 명씩 돌아가며 출제한다(한 단어 끝나면 다음 사람).
    맞히는 사람은 화면을 등지고, 출제자만 화면의 단어를 본다.
    정답 +1(Space/Enter) → 다음 단어, 패스(P) → 다음 단어. 7분 안에 많이 맞힌 팀 승리.
  🎨 캐치마인드: 한 팀씩, 팀당 7분(그림 한 장은 시간 제한 없음). 정답 +1 / 패스 → 새 제시어 + 그림판 비움.
    팀별로 한 팀씩 차례대로 하고, 팀 안에서는 팀원이 순서대로 한 명씩 돌아가며 그린다(한 문제 끝나면 휴대폰을 다음 사람에게).
    제시어는 큰 화면에 나오지 않는다(맞히는 사람도 보는 화면이라서). 그리는 사람만 휴대폰으로 본다.
    캐치마인드 탭 오른쪽 QR 을 찍으면 바로 제시어 화면(/word). 새 제시어가 나오면 진동과 함께 바뀐다.
    휴대폰 화면에는 캐치마인드 제시어만 나온다(몸으로 말해요는 큰 화면으로 진행). 휴대폰 한 대를 그리는 사람끼리 돌려 쓰면 된다.
    그림은 휴대폰 제시어 화면의 흰 판에 손가락으로 그리면 큰 화면에 바로 나온다(노트북에서 그려도 되고, 양쪽이 서로 맞춰짐).
    색·굵기·지우개·되돌리기·전체 지우기도 휴대폰에 있다. 정답·패스로 다음 제시어가 되면 그림판은 양쪽 다 자동으로 비워진다.
    휴대폰 화면에도 [⭕ 정답] [⏭ 패스] 버튼이 있다. 휴대폰과 큰 화면 어느 쪽에서 눌러도 똑같이 반영되고 서로 1초 안에 맞춰진다.
    둘이 거의 동시에 눌러도 한 번만 센다(늦게 누른 쪽에 "방금 다른 화면에서 눌러서…" 안내). 일시정지 중엔 휴대폰 버튼이 잠긴다. 화면을 누르면 단어를 가렸다 보였다 할 수 있다.
  🎲 제시어는 몸으로 말해요·캐치마인드 모두 매번 무작위로 나온다. 한 번 나온 단어는 두 게임 통틀어 다시 나오지 않는다
    (팀 기록을 지우고 다시 해도, 서버를 다시 켜도 마찬가지). 처음부터 다시 쓰려면 그 게임의 [판 초기화]/[기록 초기화].
  🏁 마치고 집계하기 (게임마다 있음): 다 못 끝냈어도 지금 결과로 그 게임 순위를 확정한다.
    빙고 = 지금 가진 칸 수로 판정 / 몸으로·캐치 = 진행 중 라운드는 그 개수로 마감, 안 한 팀은 0개.
    잘못 눌렀으면 [집계 취소 (계속 진행)].
  🗳 특별상 (닉네임 투표): 진행자 노트북 한 대에서 한 명씩 돌아가며 투표.
    투표 화면은 비밀번호 없음: http://localhost:8023/vote (팀뽑기 화면 [🗳 특별상 투표] 버튼).
    투표 화면에서는 투표만 가능. 마감·발표·표 취소·초기화는 게임 화면 🗳 특별상 탭에서.
    ① 자기 본명 → ② 닉네임 선택 → ③ 투표하기 → '다음 사람에게 넘겨 주세요' 화면으로 바뀜(1분 그대로 두면 처음으로).
    1인 1표(본명당 한 번), 자기 닉네임 투표 불가, 누가 누구를 찍었는지는 저장 안 함.
    투표 중에도 닉네임별 득표 현황(막대그래프)이 투표 화면 오른쪽과 게임 화면 특별상 탭에 실시간으로 보임.
    오른쪽 [투표 마감하고 발표] → 최다 득표 1명 발표. 동점이면 [결선 투표 시작](동점 후보만 놓고 다시 한 표씩).
    잘못 누른 사람은 [표 취소 · 초기화]에서 그 사람 표만 취소 후 다시 투표.
  🏆 최종 랭킹: 게임별 1위 3점·2위 2점·3위 1점 + 보너스(±) = 합계.
    [3등 발표] → [2등 발표] → [1등 발표] 순서로 발표 연출.
    상품: 1등 소정의 상품 / 2등 무임승차 / 3등 식사 셋팅 및 고기굽기.
  게임 기록만 지우려면 최종 랭킹 탭 [게임 기록 전체 초기화] (팀뽑기 결과는 유지).

[전체화면 타임테이블 · 휴식 화면]
  팀뽑기 화면 [🗓 타임테이블 전체화면] 또는 게임 화면 [🗓 타임테이블 · 휴식 화면] → 한 번에 전체화면.
  (직접 주소: http://localhost:8023/timetable, 비밀번호 없음)
  현재 시각·지금 순서·다음 순서까지 남은 시간이 자동으로 표시되고, 감사 문구가 돌아가며 나온다.
  B = ☕ 휴식 15분 타이머 켜기/끄기 (현재 시각 왼쪽에 박스로 표시, 타임테이블은 그대로 보임 · 끝나면 30초 뒤 자동으로 사라짐)
  Esc = 닫기 · 마우스를 3초 안 움직이면 버튼·커서가 숨겨진다.
  행사 당일 그 순서 시간이 되면: 화면 번쩍 + 큰 알림("단체사진 촬영 시간!" 등) + 카드 위 불꽃,
  진행 중인 카드는 무지개 테두리·빛줄기·빛무리·아이콘 통통·반짝이로 계속 강조된다.
  미리 보기: http://localhost:8023/timetable?now=14:49:55 (그 시각부터 시계가 흘러감, 데이터 영향 없음)
  파트너사 감사: 날짜 옆 'Special Thanks PartnerA · PartnerB' 배지 상시 표시, 감사 문구·흐르는 자막에도 포함,
  1분 30초마다 'SPECIAL THANKS TO PartnerA & PartnerB'(6초) → 'THANK YOU 참가자18 · 참가자09 · 참가자13'(6초) → '장보기의 신 참가자15'(6초) 장면이 이어서 나온다.
  날짜 옆 배지도 4초마다 회사명 → 이름 → 참가자15 순으로 바뀐다. T = 세 장면 바로 띄우기.

[인터넷으로 열기 (휴대폰 데이터에서도 접속)]
  1) start.command 로 서버를 먼저 켠다.
  2) tunnel.command 더블클릭 → 10초쯤 뒤 창에 "인터넷 주소: https://○○○.trycloudflare.com/" 가 뜬다.
  3) 팀뽑기 화면 [📱 휴대폰 접속 QR] → 그 주소가 QR 로 뜬다(빔프로젝터에 띄워서 찍게 하면 됨).
     캐치마인드 탭의 제시어 QR 도 자동으로 이 인터넷 주소를 쓴다.
  - 주소는 tunnel.command 를 켤 때마다 바뀐다(QR 은 자동으로 새 주소). 창을 닫거나 Ctrl + C 하면 인터넷 접속만 끊긴다.
  - 주소가 끊기면(맥 잠자기·Wi-Fi 변경 등) 30초마다 확인하다가 1~2분 안에 새 주소로 알아서 다시 연결한다.
    팀뽑기 QR·캐치마인드 QR 은 새 주소로 자동으로 바뀐다. 이미 열어 둔 휴대폰은 새 QR 을 다시 찍는다.
  - 창이 켜져 있는 동안 맥이 저절로 잠들지 않게 해 둔다. 단 노트북 덮개를 닫으면 잠드니 덮개는 열어 두고 전원을 꽂아 둔다.
  - 서버 노트북 자신은 인터넷 주소 대신 http://localhost:8023 으로 연다.
  - 인터넷 주소로 들어오면 누구나 팀뽑기·투표·타임테이블·게임 화면을 모두 열 수 있다(비밀번호 없음).
    관리자는 본명 사회자 선택만으로 들어가지니 주소를 단체방 밖에 퍼뜨리지 않는다.
  - 사내망에서는 화면 갱신이 2초 정도 늦을 수 있다(자동으로 조회 방식으로 바뀜). 동작에는 문제없다.
  - 처음 한 번만 cloudflared 설치가 필요하다(이미 설치됨): brew install cloudflared

[끄기]
  서버 창에서 Ctrl + C. 결과는 data.json 에 남아 다시 켜도 그대로다.

[관리자]
  본명에서 사회자(사회자) 선택 → [관리자 입장].
  팀 이동·팀장 지정·직접 배정·추첨 취소(다시 뽑기 허용)·명단 추가/삭제·다시 섞기·백업/복원·초기화.
  서버를 다시 켜면 관리자 인증이 풀리니 사회자을 다시 선택한다.

[포트 변경]
  python3 server.py --port 9023   (8023 이 이미 사용 중일 때)

[처음부터 다시]
  관리자 화면 [전체 초기화], 또는 서버를 끈 뒤 data.json 삭제.

[접속이 안 될 때]
  - 같은 Wi-Fi 주소(http://172...)는 같은 네트워크에서만 된다. 모바일 데이터면 tunnel.command 의 인터넷 주소를 쓴다
  - 게스트 Wi-Fi 는 기기끼리 통신을 막는 경우가 많다 → 사내 Wi-Fi 사용
  - macOS 방화벽이 켜져 있으면 "들어오는 연결 허용" 팝업에서 허용
